# Avalon Table

A one-phone helper for *The Resistance: Avalon*, themed with Lord of the Rings characters. Pass the phone around to deal secret characters, then use it as the quest board.

**Play:** https://michaelchacko.github.io/avalon/

## What it does

- **Setup:** pick 5–10 players, switch characters on or off, and add player names (optional, used to show who leads).
- **Reveal:** the phone shows a character number. Tap the card to see your character, tap again to hide it, then tap *Next character* and pass the phone on. When everyone has seen theirs, the app shows the narrator's night script for the characters in play.
- **Quests:** track quest results, fail counts, the vote track, the current leader, Lady of the Lake and the final assassination.
- **Rules:** the round structure plus what each character in this game knows and does.

## Running it

It's a single `index.html` with no build step. Open it in a browser, or serve the folder with GitHub Pages. Game state is saved in the browser, so locking the phone mid-game is fine.
